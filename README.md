# Have You Tried Turning It Off?

Entry for the make.fun bounty **"Have You Tried Turning It Off?"** — a program that writes one funny line a hopeless tech support agent gives a desperate customer.

## The line

> Good news — I've escalated your case to Level 2 support. Bad news — that's also me, just wearing a different headset.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

Deterministic, offline, standard library only — every run writes the exact same bytes.
